# RHCSA Labs

Documentazione dei laboratori pratici per il conseguimento della certificazione RHCSA su RHEL 10.

L'obiettivo è mostrare le competenze acquisite durante il periodo di apprendimento, tramite laboratori verificabili.

## Come lavoro

L'OS di riferimento è Rocky Linux 10, compatibile con RHEL 10, con installazione minimal.

I laboratori sono strutturati per partire da uno scenario realistico che racchiuda più argomenti d'esame. Le configurazioni che devono restare attive vengono verificate tramite riavvio.

Fonti: obiettivi ufficiali dell'esame Red Hat EX200, pagine man, documentazione Red Hat e il corso RHCSA di Sander van Vugt.

## Laboratori

Ogni laboratorio segue lo stesso schema: scenario, obiettivi d'esame coperti, ambiente, procedura, verifica, problemi incontrati e note finali.
